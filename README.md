# Chess System

This project was an important step in consolidating my Java knowledge and understanding how Object-Oriented Programming concepts can be applied to a larger problem involving different classes, responsibilities, and business rules.

Besides the technical side, I also had to learn more about how chess works. So, in addition to practicing Java, I finished the course knowing a little more about how the pieces move and why not every move that looks good is actually a good move.

This project was developed for learning purposes, following the Java course by Nélio Alves.

## What I Learned

Throughout the development of this project, I was able to practice and better understand:

- **OOP:** encapsulation, inheritance, polymorphism, abstract classes, and interfaces.
- **Code Organization:** separation of responsibilities into layers, keeping the game logic more organized.
- **Data Structures:** using matrices to represent the chessboard and lists to manage the pieces.
- **Programming Logic:** implementing and validating moves, identifying possible moves, and managing turns.
- **Exception Handling:** validating user input and handling invalid moves.
- **Chess Rules:** implementing piece captures, check, checkmate, castling, en passant, and pawn promotion.

## Features

- Chessboard displayed in the terminal.
- Piece movement according to chess rules.
- Display of possible moves.
- Turn-based gameplay.
- Tracking of captured pieces.
- Validation of invalid moves.
- Check and checkmate detection.
- Support for special chess moves.

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Terminal
